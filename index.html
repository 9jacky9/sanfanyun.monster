SPECTRAL KNOWLEDGE BASE

关于三番云的常见技术问答

快速了解我们的多平台订阅机制、IPv6双栈兼容性与服务承诺。

1. 什么是“三棱光谱分流”，需要我手动编写复杂规则吗？

完全不需要手动编写。当您在 Clash、Shadowrocket、Sing-box 或 Surge 中导入三番云的自适应节点连接通道时，云端已为您预置了经过严密测试的三棱光谱分流策略。国内网站毫秒直连，海外流媒体、AI算力与游戏流量会自动匹配至各自最适合的专线节点组。

2. 开发者在终端执行 git clone 或 docker pull 时如何生效？

您可以在客户端中一键开启“TUN虚拟网卡模式（增强模式）”。开启后，无论是命令行终端里的 SSH/Git 请求、Docker 守护进程拉取镜像，还是 IDE 内的 AI 补全插件，都会在操作系统内核层被透明接管加速，无需配置繁琐的环境变量。

3. 家庭宽带开启了 IPv6 会影响加速效果或导致真实位置泄漏吗？

三番云全线支持 IPv4/IPv6 双栈安全接管与防泄漏保护。客户端规则会自动接管所有双栈 DNS 查询并阻断非预期的直连回退，同时在支持 IPv6 的海外落地节点上提供原生双栈解锁能力。

4. 流量用完了或者想升级更高档位套餐怎么办？

用户中心支持随时一键重置当月流量包或平滑升级至更高阶套餐。所有节点均不限制月度内的正常高频使用，并且我们提供全天候在线客服为您解答任何配置疑问。
